# CPU matchup ranking against Rivet

On 26 November 2026, the browser combat engine completed 200 CPU-versus-CPU matches between Rivet and the other 40 fighters, plus five Rivet mirror matches. Rivet finished 82–118 against the roster (41% wins). Eight fighters went 5–0. Incantus, Kiln, and Vidarr tied for first and won every match with at least two stocks left. Luffy and Zunchy went 0–5. Those results flag the strongest and weakest CPU matchups against Rivet in this run.

## Match rules and schedule

Each fighter faced Rivet once in each of the five standard arenas, starting on the left either two or three times. Each arena had 20 challengers start on each side. Matches used the browser game's 3 stocks, 3-minute limit, 120 Hz simulation step, and standard arena and Superstar rules. Both slots used the built-in CPU with an empty controller input map.

Rank uses one point per win and half a point per draw. Tied scores use cumulative stock differential, the sum of the challenger's remaining stocks minus Rivet's. Ranks remain tied when both values match. Each arena cell shows the outcome and final stocks from the challenger's perspective. W, L, and D stand for win, loss, and draw. An asterisk marks a time limit finish.

## Reproduction

Run the browser combat engine at commit `e333be8b846a462cc53a9495d2c4051b45f0320c` using `createMatch` and `tickMatch`. Iterate through the fighter and arena registries in source order with zero-based indices. Seed Mulberry32 once per match with `261126 + fighterIndex * 5 + arenaIndex` and use it for `Math.random`. Assign the challenger to slot `(fighterIndex + arenaIndex) % 2` and Rivet to the other slot, with both marked as CPU. Step the match until the engine returns an official result. A second run with the same seeds reproduced all outcomes, final stocks, damage, and durations.

Five matches against one opponent measure the matchup in this CPU sample. Overall roster balance and human play require results across more opponents and play styles.
